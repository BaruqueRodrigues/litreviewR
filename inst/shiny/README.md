# Interface Shiny local

A interface principal é entregue por `litreviewR::configura_revisao()`. Depois
de instalar o pacote e suas dependências, abra o R e execute:

```r
litreviewR::configura_revisao()
```

Para uma conferência visual rápida: (1) abra a aba **Instrumento** e altere a
área; (2) adicione uma dimensão, preencha nome, instrução e categorias; (3)
desative e reative uma dimensão e mova-a na lista; (4) confira a aba **Prévia**;
(5) exporte o JSON, reimporte-o e confira a validação. A interface não exige
chave de API e não envia conteúdo a serviços externos.
